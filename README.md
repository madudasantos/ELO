# ELO — Plataforma solidária (protótipo frontend)

Projeto acadêmico para conectar ONGs, doadores e voluntários do Vale do Rio dos Sinos.

## Como executar

Abra `index.html` no navegador ou utilize a extensão Live Server no VS Code. Os arquivos são `index.html`, `style.css` e `script.js`. Não há instalação de dependências.

## Recursos

Navegação por páginas e fluxos demonstrativos de campanhas, doações, voluntariado, cadastro de ONGs, favoritos, perfis, painel de gestão e preferências. Os registros são salvos localmente no navegador.

## Limitações

- **Protótipo acadêmico, não uma plataforma em produção.**
- Não há pagamentos, transferências bancárias, envio de e-mail, consulta oficial de CNPJ, autenticação segura ou análise documental real.
- Organizações, campanhas e números são ilustrativos.
- A versão publicada ainda não foi validada como reprodução fiel das 82 páginas do PDF original.
- Não informe dados bancários, documentos ou senhas reais.

## Estrutura

- `index.html` — página principal.
- `style.css` — estilos e responsividade.
- `script.js` — interações e dados demonstrativos.
